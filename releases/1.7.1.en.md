# HakuX-Mali 1.7.1 / code31

Restores the agreed game launch choice that was omitted from release 1.7. Selecting a game in the library now opens a dialog with two actions:

- **Start a new game** performs a normal launch without restoring an emulator state. Existing states and in-game saves are kept; loading through the game's own menu remains available.
- **Load latest save** restores the newest emulator state for that title. It compares modification times across autosave, quick save and manual slots 1–10, and displays the slot and date.

The same dialog serves All games, Recently played and search results. It includes Cancel and Russian/English text. Loading is disabled with an explanation when no state exists. State checks run off the UI thread and are repeated before loading; a removed file never silently triggers a cold start. The previous resume-offer setting is hidden because the choice is now available on each library launch.

## Preserved features

All 1.7 features remain: manual selection and ZIP driver import on every model, Unified P77r1 and the three earlier bundled packages. All eight native libraries and four driver ZIPs are byte-identical to 1.7. The icon, HUD, 120 FPS cap, control editor and game fixes are retained. This is an in-place update with the existing signing key and application ID.

## Validation

- The final APK was installed over 1.7 on RG477M, RG476H and RG Rotate. All games, recent games and search entry points were checked on each.
- RG477M: Mafia cold launch reached its title screen; a separate slot 1 restore completed successfully.
- RG476H: NFS Most Wanted Black Edition slot 1 restored into a race, with successful completion confirmed in the native log.
- The no-state disabled action was checked. The English dialog and button visibility were checked on Rotate's square display.
- 122 unit tests, including 6 latest-state selection tests, and `lintVitalRelease` passed.
- On RG477M and RG476H, settings, active driver, HXS, thumbnails and cache blob payload hashes were checked. Restoring Mafia refreshed its native cache bookkeeping index; state payloads were unchanged. On unrooted Rotate, in-place update, original app UID, P52 selection and accessible packages were verified; private settings could not be byte-compared.

This patch adds no new FPS benchmark or GPU qualification. RG Vita Pro support is retained from earlier releases; this build was not retested on that device. P77r1 qualification scope and driver sources remain available in [release 1.7](https://github.com/Wannamingo/HakuX-Mali/releases/tag/v1.7).

No BIOS, HDD, game images or user save states are included in the APK or public materials.
