# HakuX-Mali 1.7 / code30

Released November 6, 2026. APK 1.7/code30 was installed over 1.6.1 on RG477M,
RG476H and RG Rotate. All three passed manual bundled P77r1 selection, custom
ZIP import through the system picker, persistence after app restart and
selection of System. Their original M2+DS1, System and P52 selections were
restored afterwards. Settings and game data were preserved.

## Manual drivers on every device

Settings → GPU driver, System driver, every bundled package and custom ZIP
import are available regardless of device model, SoC or GPU vendor. Chip
detection provides recommendations and the historical initial default.
Updates preserve explicit choices and do not automatically enable the new
Unified package. Existing touch-button artwork, app icon, HUD and 120 FPS
limit are preserved.

ZIP structure, metadata, contained paths, the ARM64 library and the package's
minimum Android version are still checked. Driver startup errors have RU/EN
messages; the selected package is retained until the user changes it.
Availability of an import option does not establish compatibility between
every binary, GPU and firmware kernel.

## Bundled Unified P77r1

P77r1 is the fourth option. Official MaliSX2 0.2.3, M2+DS1 and Unified P48r1
remain available with their original package identifiers.

Existing Unified fixes are retained alongside selected accepted MaliSX2
changes through 0.3.3. The driver changes include:

- linear descriptor-set allocation, partial-batch rollback and pool reset;
- corrected G52 tiler-memory bounds and an adaptive JM memory ring;
- eligible BGRA8 and D24S8 AFBC targets;
- direct VS→FS output specialization and raster/attachment LOAD fixes;
- 3D blit fixes, including linear Z interpolation;
- no advertisement of unqualified BC1–7 texture formats.

The driver package requires ARM64 and Android 12/API31 or later. Its exact
ELF was checked on RG477M/Mali-G615, RG476H/Mali-G57 and RG Rotate/Mali-G52.
Other GPUs are not thereby qualified. G52/G57 advertise Vulkan 1.1. G615's
experimental Vulkan 1.4 advertisement is not full Vulkan 1.4, GS/tessellation
or descriptor-indexing conformance.

## Validation scope

The exact P77r1 release ELF completed 18 native processes across the three
consoles: 48 BC format checks, 39 linear-pool cases, 48 colour/depth LOAD cases
covering 786,432 pixel coordinates, 72 repeated-graphics cases and 9 Android
native-buffer import cases.

A separate G615 AHardwareBuffer/BufferQueue test completed 349,527 checks and
200 frames. It used a private RGB_EXTERNAL override; this does not enable
that mode in the application or expose public AHB on G52/G57. The earlier
incomplete diagnostic run remains separate and was not counted as a pass.

Validation included actual driver identity, raw results, kernel logs,
temperature and preservation of APKs, selected drivers, settings and states.
Private settings on stock unrooted RG Rotate cannot be byte-hashed; its
preservation evidence uses accessible checks and no appdata writes. New game
FPS comparisons and long-session stability are not established. The driver-selection and import UI was checked on all three devices; this
stage adds no new gameplay FPS measurement.

No BIOS, HDD, games or save states were added to the APK. All eight core and
support libraries remain byte-identical to the validated 1.6.1 APK. Driver
licenses, provenance and the detailed test matrix are inside its ZIP.

## UI and update checks

[Validation matrix](../docs/VALIDATION-1.7.json) · [Screenshots](../docs/screenshots/1.7/README.md).
Settings, active driver and states were verified by exact hashes on RG477M
and RG476H. On stock unrooted Rotate, the original P52 selection after app
restart, application UID, accessible files and UI values were checked;
private settings cannot be hashed. Temporary imported test copies were removed.
No full HDD/state backup was made. All 116 unit tests and lintVitalRelease passed.

To test a driver, open Settings → GPU driver, select a bundled option or
use Add a driver with your ZIP, then restart the game. In a bug report,
include device model, GPU/SoC, firmware and Android, driver name, game and
scene; a comparison with System in the same scene is useful.
