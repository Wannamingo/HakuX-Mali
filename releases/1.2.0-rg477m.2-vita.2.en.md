# HakuX for RG477M: ANBERNIC RG VITA Pro

[Русский](1.2.0-rg477m.2-vita.2.ru.md) | [English](1.2.0-rg477m.2-vita.2.en.md)

**Experimental ANBERNIC RG VITA Pro support** is added to release 1.2.0-rg477m.2 as a separate APK **1.2.0-rg477m.2-vita.2** (versionCode 12). Tested on 2026-10-29. [Download the Vita Pro APK](https://github.com/Wannamingo/HakuX-Mali/releases/download/v1.2.0-rg477m.2/hakuX-RG-Vita-Pro-1.2.0-rg477m.2-vita.2-release.apk).

## Changes

- RG VITA Pro / RK3576 / Mali-G52 support on Android arm64. Tested on Android 14 / GammaOS Next Lite; other firmware is not established as compatible.
- Fixed system Vulkan 1.3 startup on Mali-G52: optional bindless features are requested only when supported. This resolves `VK_ERROR_FEATURE_NOT_PRESENT` at `vkCreateDevice` on the tested system driver.
- Bundled official MaliSX2 0.2.3 includes Mali-G52 v7. Both MaliSX2 and System driver are available; System was faster for Most Wanted at 2x. Restart the game after changing drivers.
- CPU, GPU and battery temperatures added to the single-line FPS HUD. Background sampling every 2 seconds; no root or new permissions. Unavailable sensors are not replaced with other types of readings.
- Retained the supplied icon, 120 FPS upper bound, earlier RG477M workarounds and fork update feed. FEX source was not modified.

Recommendations: **minimum load - System 1x, FXAA Off; balanced - System 1x, FXAA On; higher clarity - System 2x, FXAA Off**. Bilinear; async shaders and prebuild On; Uncapped Off. Start at 1x with passive cooling. 3x/4x are not recommended for this scene.

The original MaliSX2 2x failure reported `0x60 (out of memory)` followed by `VK_ERROR_DEVICE_LOST`. It did not recur in the controlled tests, but is not claimed fixed. DOA Xtreme Beach Volleyball additionally reached its intro/title at approximately 60 FPS; this is not an in-level benchmark. The older 31 confirmed RG477M startups do not establish Vita Pro compatibility.

## Installation and APK selection

For **RG VITA Pro**, manually download `hakuX-RG-Vita-Pro-1.2.0-rg477m.2-vita.2-release.apk`, install over our earlier build, select your own Xbox ISO/XISO folder and start with System driver / 1x. Existing explicit driver choices are retained; bundled MaliSX2 remains in Settings → GPU driver. A fresh supported installation may select MaliSX2 automatically; select System explicitly to reproduce this benchmark.

For **RG477M**, the existing `hakuX-RG477M-1.2.0-rg477m.2-release.apk` remains a separate asset. The Vita Pro APK uses the same package ID and certificate; both builds cannot be installed side by side in one Android profile. The shared release feed does not automatically choose the Vita Pro APK by device model: download the named file manually.

Build checks: Native Release, Android release/R8, lintVitalRelease, **28 JVM tests**, 7 native libraries, 20 icon resources, v3 signature and 16 KiB alignment. The published APK is identical to the installed and benchmarked file; it was not rebuilt after measurement.
