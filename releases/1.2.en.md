# HakuX-Mali 1.2

[Русский](1.2.ru.md) | [English](1.2.en.md)

Released 2026-10-30. **App version 1.2, versionCode 20**, based on hakuX 1.2.0. Android 9+ / arm64-v8a, optimized release build. RG477M / Mali-G615 support and experimental RG VITA Pro / RK3576 / Mali-G52 support are retained. MaliSX2 0.2.3 is bundled; the HX icon, signing certificate and package ID are retained.

## New interface

### Library and in-game menu

- The library offers a cover grid and compact list, adjustable card sizes, recently played games and custom cover images.
- ISO/XISO images and folders containing `default.xbe` share the library. Each game folder appears as one card; resource directories do not become separate games.
- The pause menu is a sidebar containing resume, current-game settings, touch controls, controllers, save/load state and return to library.
- Navigation supports the D-pad and A/B/Start buttons. Returning from settings to the game and the fallback Start handling have been fixed.

### Categorized settings

Settings are organized into **Graphics, Display & HUD, Controllers, Games & Data, Xbox System, and Application**. Each category retains its own scroll position. Fixed a drawing issue that could leave the previous category visible after switching tabs.

Search accepts Russian and English setting names, opens the matching category and highlights the target row. The on-screen keyboard no longer covers results; autocorrection is disabled for search.

Global settings and **current-game overrides** have distinct scopes. Inherited and overridden values are visible. Resetting a game's overrides requires confirmation and affects only that game's overrides. Not every global setting has a per-game counterpart.

### Russian and English

Choose **System, English or Русский** in Application settings. The library, pause menu, settings and dialogs are localized. The interface language is independent of the emulated Xbox language. Switching menu language does not restart the running guest game.

## Graphics profiles and picture controls

A profile changes exactly four settings, preserving the Vulkan driver, Xbox video mode and compatibility fixes.

| Profile | Resolution | FXAA | Upscaling | FPS limit |
|---|---|---|---|---|
| Performance | 1x | Off | Bilinear | 60 |
| Balanced | 1x | Off | GSR | 120 |
| Quality | 2x | On | GSR | 120 |

Manually changing the combination produces a Custom profile. Profile names do not guarantee a particular frame rate on every device. Earlier RG VITA Pro measurements suggest starting with **System driver / 1x**.

- Each game can override the global FPS limit or inherit it. The menu offers unlimited, 30, 60, 90 and 120. The fresh-install global default remains **120 FPS**; updates retain saved choices. A game's own 30/60 FPS limit still applies.
- Added brightness **50–150%**, contrast **50–150%**, saturation **0–200%**, gamma **50–200%**, and GSR strength **0–100%**. Picture settings apply **on the next game launch**, as stated in the menu.
- All these controls default to **100%**, preserving the previous image. GSR 0% uses bilinear upscaling, 50% blends the two, and 100% uses the original GSR output.
- **GSR is an upscaling filter**, independent of the MaliSX2 driver. Its interface label is “GSR — sharper upscaling”.
- Color adjustment runs in the existing presentation path after the Xbox gamma ramp, without adding a render pass.

## Configurable HUD and temperatures

The HUD retains **one line** for FPS, average/last frame time and selected available temperatures. There are no lower diagnostic rows.

- Font size **8–18 sp**, default 11 sp.
- Four corner positions, default top left.
- Background opacity **0–100%**, default 40%.
- CPU/SoC, GPU and battery temperatures can be toggled independently. Unavailable sensors are omitted; CPU may use an available SoC reading.
- Temperature polling stops when all temperature indicators are disabled. The normal polling interval is two seconds.
- HUD changes apply when returning to the game from settings. Long lines are ellipsized without silently reducing the selected font size.

## Syberia fixes

Fixed dirty-page accounting after 2D background copies, for both GPU copies and CPU uploads. A repeated stale background upload should no longer erase already rendered 3D graphics. GPU readback and CPU copy ordering were also corrected, resolving the checked character trails after scene changes. These two changes belong to the general copy path.

For **Syberia / MaliSX2 without zero-copy**, an extra full-frame idle-boundary synchronization is specifically restricted: it could restore an old menu background after selecting an option. Normal synchronization remains; the special condition does not apply to other games. The owner confirmed correct background refresh and working behavior. This does not guarantee that every rendering issue in every game is fixed.

Retained earlier startup fixes for Syberia and Ultimate Beach Soccer, Ultimate Spider-Man memory fixes, Serious Sam visibility-query fixes, Warrior Within video fixes, The Two Thrones geometry fixes, and The Sands of Time bloom/flickering-block fixes. [Complete earlier change list](1.0.en.md).

## Serious Sam: instructions for Russian-language packages

The checked **T-Rus Ryudo** folder package hangs in the added menu/trainer chain: `default.xbe → game.xbe → eng.xbe`. Direct launch of the actual game reached gameplay.

1. Close the game.
2. Back up the original `default.xbe` under an unused name, such as `default.xbe.hakux-launcher.bak`.
3. **Copy `eng.xbe` to `default.xbe`**, keeping the original `eng.xbe`.
4. Leave all other files, including `.gro` resources, unchanged. Refresh the library and launch the folder.

This bypasses an added loader in folders with these files; it is not an automatic patch for all Russian versions. **Preservation of Russian localization with the English `eng.xbe` was not confirmed.** Read the **[English instructions](../docs/SERIOUS-SAM.en.md)** or **[prominent Russian guide](../docs/SERIOUS-SAM.ru.md)** for applicability and reversal. No game files are included in the release.

## Validation and limits

Version 1.2 preserves the native libraries, MaliSX2 and icon images from the tested versionCode 19 UI build. Validation for this line includes **46 JVM tests**, release/R8, lintVitalRelease, compilation of all five embedded GLSL shaders for Vulkan 1.1/1.3, v3 signature checks and 16 KiB ZIP/ELF alignment. RG477M checks covered categories, search with the keyboard, RU/EN/System switching, profiles, per-game settings, picture controls, HUD, return to the running game, saved Syberia scenes and direct Serious Sam startup. The final 1.2 APK was installed over the previous build, verifying existing savestate checksums and retained settings; the screenshots were captured from it.

[31 historically confirmed RG477M startups](../docs/COMPATIBILITY.en.md) do not mean all games were re-tested on 1.2 or completed. No new 1.2 RG VITA Pro benchmark was performed; the [earlier Most Wanted report](../docs/RG-VITA-PRO-PERFORMANCE.en.md) remains a reference subject to its stated limits. Earlier Vita Pro device-lost/out-of-memory cases are not declared fixed. The Call of Cthulhu opening cinematic retains a texture defect; all Ultimate Spider-Man comic scenes and Conker have not received complete gameplay validation.

## Installation and sources

Install **HakuX-Mali-1.2-release.apk** over our previous build. The signing certificate, package ID `com.rfandango.haku_x.debug`, game access, settings and saves are retained. A very old build may require manually installing the APK once; future update checks use **Wannamingo/HakuX-Mali**.

Release assets include the APK, corresponding source archive with submodules and the native dependencies used, a patch against hakuX 1.2.0, revision manifest, validation report, RU/EN documentation, PNG screenshots and SHA-256 checksums. GitHub's standard Source code archive omits submodule contents. GPLv3+; hakuX, FEX and other component credits are preserved. No games, HDD images or user data are distributed.
