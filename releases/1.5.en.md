# HakuX-Mali 1.5 — stable release, code24

[Русский](1.5.ru.md) | [English](1.5.en.md)

One APK for **ANBERNIC RG477M, RG Vita Pro and RG Rotate**, based on hakuX 1.2.0. Combines validated renderer controls, bundled M2+DS1 and user-approved shaders/masks. Retains game fixes, artwork, bilingual UI, single-row FPS/frametime/temperature HUD, the 120 FPS ceiling and all [1.4 features](1.4.en.md).

## Shaders and masks

Open **Settings → Display and HUD → Shaders**, or **Pause → Shaders**. Five presets: Off, light CRT, soft/curved CRT, composite NTSC and temporal CRT with flicker/jitter. The temporal effect also redraws held guest frames; these redraws do not increment guest FPS.

CRT mask choices: Off, RGB stripes (LCD style), round dots (CRT monitor), slots (CRT TV), diagonal (XO-1 style) and sparse (OLED style). These are stylized patterns, not exact physical-panel simulations. Mask size is 1–8 screen pixels, independent of internal game resolution. Controls include mask strength 0–100%, scanlines 0–80%, glow 0–30%, blur 0–100% and curvature 0–30%. NTSC is a separate effect; CRT masks do not apply to it.

Global values can be inherited or overridden per game and travel with exported profiles. Disabling an effect retains its adjustments. Reset to preset restores that effect's defaults. The pause panel has **Apply** for the complete draft and **Cancel** to keep current values. Shaders are off by default. Cost depends on the scene/device; there is no separate comparative gameplay FPS benchmark with effects enabled.

## New picture controls

- **Anisotropic filtering:** original sampling, 2×, 4×, 8× and 16×, bounded by the loaded driver. Supported levels appear after a game starts; changes require restarting it. Applies to suitable linearly sampled mipmapped 3D textures; video, fonts, palettes and utility textures retain original sampling.
- **Movie aspect ratio:** game layout, 4:3, 16:9 or recognized source ratio. Detection uses Bink metadata and fullscreen video overlays. Unknown cutscenes have a manual pause-menu action and assignable shortcut. Auto does not identify every engine-rendered or anamorphic movie; a Bink stream already open when restoring a state may need manual mode. Normal game 4:3/16:9 switching is retained.
- **Dynamic resolution:** experimental live internal scale from 1× to 2×, with a configurable range and 30/60/90/120 FPS goal. Adaptation pauses in recognized movies, 2D scenes and calibration. Downscaling is retained with at least 5% FPS improvement; upscaling requires at least 95% of the target. Unhelpful probes roll back. Disabling restores the launch's fixed scale. Transitions need temporary memory and can cause a short hitch.

Defaults retain original filtering/game aspect, with dynamic resolution off. Settings support global values, game overrides and portable profiles. Picture changes require recalibrating measured profiles. A target cannot override a game's own cap. The controller uses FPS and host-observed graphics-queue waiting: **not GPU timestamps or precise GPU utilization**.

## Bundled driver

**MaliSX2 0.2.3 Unified M2+DS1** is bundled for RG477M/Mali-G615 on Android 14+: M1/M2 fixes and same-format NEAREST depth/stencil blits. Official MaliSX2 0.2.3 remains available for selection and other supported devices. The driver is loaded within the app. Explicit existing choices, including System, survive updates; restart the game after switching.

M2+DS1 passed 5,200 M1/M2 API checks, 1,936 DS cases, 60 coupled cases and HakuX startup/scale-transition checks. Syberia M2–M5 comparisons were essentially equal: about 60 FPS at 1× and 47.5–47.7 FPS by the fireplace at 2×. This is not a general speedup claim. M6/P3 and experimental memory-upload changes are not included. On Vita Pro/Rotate start with System, 1×, Bilinear, FXAA Off and shaders/DRS off.

## Validation and performance

New features were checked on **RG477M**. Vita Pro/Rotate support is retained from 1.4; the new shaders/DRS were not tested on those devices in this series.

- The user approved shader/mask output in the installed preview. CRT/NTSC/temporal pipelines passed technical startup on RG477M.
- 74 Android unit tests, Kotlin and lintVitalRelease; 16 production GLSL compilations for Vulkan 1.1/1.3. APK signing and 16 KB ZIP/ELF alignment verified.
- Real 8×/16× samplers, manual aspect switching and Warrior Within movie entry/exit confirmed.
- Syberia bidirectional live transitions took about 62–68 ms with the official driver; the observed scene went from roughly 45–49 FPS at 2× to 57–59 at 1×. A separate M2+DS1 run confirmed 2×→1× in about 33.6 ms. These are different local runs, not a comparable general driver benchmark.
- GPU copy probe: 8 colour/depth/stencil formats, sizes 16/25, mip0/1 and layer1, 32 cases with independent intermediate and roundtrip oracles; all defined values matched. This does not cover every AFBC variant or game stencil effect.
- Installation/technical checks preserved settings, selected driver and all 97 state files; temporary settings were restored.

Earlier 1.5 calibration on RG477M, one Syberia checkpoint, DRS and new shaders off:

## Updating and compatibility

Install **HakuX-Mali-1.5-release.apk** over our existing app. Code24 updates stable 1.4/code22 and code23 previews. Package ID and signing certificate are unchanged; **do not uninstall first**. Settings, folder access and saves remain. Native core and driver assets match the approved shader preview; release metadata and documentation changed.

Retains measured calibration, audio/HRTF, profiles, cropping/zoom/position, refresh selection, quick/automatic saves, controller shortcuts, sticks/rumble, temperatures, ES-DE and updates from our repository. Games launch from ISO/XISO or folders containing `default.xbe`.

**Russian T-Rus Ryudo Serious Sam:** [instructions](../docs/SERIOUS-SAM.en.md): back up `default.xbe`, then copy `eng.xbe` as `default.xbe`. The owner confirmed Russian voice audio; Russian text was not separately checked. The emulator does not modify game files automatically.

The list of [31 previously confirmed launches](../docs/COMPATIBILITY.en.md) is retained. It does not certify full completion or retesting every game on 1.5. Missing intro textures in Call of Cthulhu remain; all Spider-Man comic scenes/long sessions are not verified; Conker is outside confirmed tests.

Release assets include app sources with FEX/native dependencies, bundled M2+DS1 sources/licenses, a patch, checks and hashes. Games, BIOS/HDD and user data are excluded. Original hakuX/FEX/MaliSX2/Mesa authorship is retained.
