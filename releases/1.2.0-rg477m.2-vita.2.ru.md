# HakuX for RG477M: ANBERNIC RG VITA Pro

[Русский](1.2.0-rg477m.2-vita.2.ru.md) | [English](1.2.0-rg477m.2-vita.2.en.md)

**Экспериментальная поддержка ANBERNIC RG VITA Pro** добавлена в релиз 1.2.0-rg477m.2 отдельным APK **1.2.0-rg477m.2-vita.2** (versionCode 12). Дата проверки: 29.10.2026. [Скачать APK Vita Pro](https://github.com/Wannamingo/hakuX-for-RG477M/releases/download/v1.2.0-rg477m.2/hakuX-RG-Vita-Pro-1.2.0-rg477m.2-vita.2-release.apk).

## Изменения

- Поддержка RG VITA Pro / RK3576 / Mali-G52 на Android arm64. Проверена Android 14 / GammaOS Next Lite; совместимость других прошивок не установлена.
- Исправлен старт системного Vulkan 1.3 на Mali-G52: необязательные bindless-функции запрашиваются только при их наличии. Устранён `VK_ERROR_FEATURE_NOT_PRESENT` при `vkCreateDevice` на проверенном системном драйвере.
- Встроенный официальный MaliSX2 0.2.3 включает Mali-G52 v7. Он доступен вместе с System driver; для Most Wanted системный драйвер оказался быстрее в 2x. Выбор драйвера применяется после перезапуска игры.
- Температуры CPU, GPU и батареи добавлены в одну строку FPS HUD. Опрос раз в 2 секунды в фоновом потоке, без root и новых разрешений. Недоступные датчики не подменяются другими показателями.
- Сохранены иконка, верхний лимит 120 FPS, прежние исправления RG477M и источник обновлений нашего форка. Не изменялись исходники FEX.

## Установка и выбор APK

Для **RG VITA Pro** вручную скачайте `hakuX-RG-Vita-Pro-1.2.0-rg477m.2-vita.2-release.apk`, установите поверх нашей версии, выберите папку своих Xbox ISO/XISO и начните с System driver / 1x. Прежний выбор драйвера сохраняется; встроенный MaliSX2 остаётся доступен в Settings → GPU driver. На новой поддерживаемой установке может быть автоматически выбран MaliSX2, поэтому для повторения теста переключите драйвер явно.

Для **RG477M** прежний APK `hakuX-RG477M-1.2.0-rg477m.2-release.apk` остаётся отдельным файлом. APK Vita Pro имеет тот же package ID и сертификат; две версии не устанавливаются параллельно в одном Android-профиле. Общий список релиза не выполняет автоматический выбор Vita Pro APK по модели устройства: скачайте файл с нужным названием вручную.

Проверки сборки: Native Release, Android release/R8, lintVitalRelease, **28 JVM-тестов**, 7 native-библиотек, 20 ресурсов иконки, подпись v3, выравнивание 16 KiB. APK совпадает с установленным и протестированным файлом; пересборка после замеров не выполнялась.
