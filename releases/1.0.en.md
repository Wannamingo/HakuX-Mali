# HakuX-Mali 1.0

[Русский](1.0.ru.md) | [English](1.0.en.md)

Released 2026-10-30. The project is now **HakuX-Mali**, application version **1.0** (versionCode 15), based on hakuX 1.2.0. Android arm64-v8a, optimized non-debuggable release.

## New

- Updated artwork: the supplied HX image is now the app icon, including adaptive and themed variants; the supplied banner heads both GitHub language pages. Corresponding sources are tagged `v1.0-branding.1`; the original `v1.0` tag is retained.
- Direct launch from game folders: `default.xbe` and all other game files are read in place. Creating or copying an ISO is unnecessary.
- Each game folder appears as one library card with a Folder badge, title and Xbox Title ID. Nested resource directories do not become separate games. An image and a folder of the same game can appear separately.
- Image launch is retained. Select `default.xbe`, a game folder or a directory containing several games; a game chooser appears when needed. File indexing runs off the UI thread and can be cancelled.
- Absolute paths supplied by game frontends reuse an existing SD-folder grant without requesting broad storage access.
- App branding, Russian/English pages and the update source now use **Wannamingo/HakuX-Mali**. The icon, signing certificate and package ID are retained.

## Retained RG477M fixes

- MaliSX2 import/loading on RG477M, actual driver verification and explicit load errors.
- A bounded 64-fence completion queue and compatible presentation for drivers without timeline semaphores.
- Syberia and Ultimate Beach Soccer: fixed early exit from file-backed images by handling the in-memory XBE media flags.
- Serious Sam: guest SEH delivery and REP MOVS progress recovery fix the startup crash.
- Ultimate Spider-Man: PAGE_WRITECOMBINE attributes are preserved using the expanded upstream 1.2.0 memory fix, including MmSetAddressProtect and compatible MM v2 state fields.
- Serious Sam: unavailable/incomplete visibility queries no longer become false zero results, fixing black flicker and severe input delay.
- Warrior Within: linear video textures are matched by pitch, texel size and dimensions, fixing stripes and the stretched lower half of cutscenes.
- The Two Thrones: unaligned vertex arrays are repacked without changing attribute values, fixing excess character geometry and triangles.
- The Sands of Time: exact bloom texture bounds remove the green right edge while retaining the effect.
- The Sands of Time / MaliSX2 0.2.3: splitting legacy render passes at blend/write-mask transitions and synchronizing attachments remove flickering black sky/floor blocks.
- FPS limits: unlimited, 30, 60, 90 or 120. The tested console retains 120 FPS; the limiter avoids a frame backlog and preserves a game’s own lower cap.
- The release HUD has one row for FPS, average/last frame time and available CPU/GPU/battery temperatures. Lower diagnostic rows and temporary experimental modes are absent.
- The supplied artwork is used for legacy, adaptive and monochrome icons across five densities, preserving its aspect ratio.
- Updated to hakuX 1.2.0, retaining upstream audio, memory, thread-stack, controller and System Link changes. present_cpu_wait and rop_pass_split have distinct bits; fpslimit uses the shared parser, and the adrenotools hooks are built together.

## RG VITA Pro and temperatures

Retains experimental **ANBERNIC RG VITA Pro / RK3576 / Mali-G52** support: system Vulkan 1.3 startup checks optional features, bundled MaliSX2 0.2.3, and a single-line temperature HUD. Available CPU/GPU/battery sensors are sampled in the background every 2 seconds; missing sensors are omitted.

Earlier Most Wanted measurements on Vita Pro: **System 1x — 30 FPS**, **System 1x + FXAA — 30 FPS**, **System 2x — 29.9 FPS**, **MaliSX2 2x — 21.4 FPS**. Start with System / 1x. These results were recorded on 1.2.0-rg477m.2-vita.2 with the same native core; they are not a new Vita Pro benchmark of 1.0. [Methodology, temperatures and limits](../docs/RG-VITA-PRO-PERFORMANCE.en.md).

This is not a full playthrough or a fresh test of every previously confirmed title.

## Installation and limitations

Install **HakuX-Mali-1.0-release.apk** over our previous build. Install 1.0 manually once when migrating from the old name: earlier builds use the old update address and a different numbering scheme. The increased Android versionCode, retained signing certificate and package ID `com.rfandango.haku_x.debug` allow an in-place update with data and settings preserved. For a new installation, select the directory containing your own Xbox images or game folders; each game folder needs `default.xbe` and the remaining game files.

The previously reported Call of Cthulhu intro texture defect remains. Long sessions and every Ultimate Spider-Man comic scene were not checked. The earlier MaliSX2 out-of-memory / device-lost failure on Vita Pro is not claimed fixed. [Compatibility list and test scope](../docs/COMPATIBILITY.en.md).

GPLv3+; hakuX, FEX and other component credits are preserved. Corresponding sources, required dependencies and licenses are attached separately. Games, HDD images, user data and private signing keys are excluded.
