# HakuX-Mali 1.6

[Русский](1.6.ru.md) | [English](1.6.en.md)

> Draft release **1.6/code26**. The final APK and bundled Unified P48r1 passed the checks described below; checksums are attached. The public stable version remains 1.5.

One Android ARM64 build for **ANBERNIC RG477M, RG476H, RG Vita Pro and RG Rotate**. The HX icon, HakuX-Mali branding, signing certificate, package ID, fork update feed, ISO/XISO and game-folder support, per-game profiles, states, on-screen controls and version 1.5 features are retained.

## RG476H support

Added support for RG476H with **Mali-G57 and Android 13**. Device compatibility, loading a particular driver package, and running a particular game are verified separately. Updates preserve the user's selected GPU driver.

Start with **1×, Bilinear, FXAA off**. Then try FSR 1 or compare measured configurations in a stable gameplay scene. Higher resolution and heavier effects increase GPU load; a result from one scene does not describe the entire library.

RG477M / Mali-G615 support is retained. Previous RG Vita Pro and RG Rotate validation keeps its original scope; every new feature in this version was not rechecked on those devices.

## Shared Unified P48r1 driver

A bundled package is prepared for **RG476H / Mali-G57 / Android 13+** and **RG477M / Mali-G615 / Android 14+**, using the same tested library on both platforms. Earlier MaliSX2 0.2.3 and M2+DS1 packages remain available, and updates retain explicit user selections. Fully restart the application and game after changing drivers.

On G57, standard uniform-buffer layouts (`uniformBufferStandardLayout`), framebuffers with deferred image assignment (`imagelessFramebuffer`), and compatible image-format lists (`VK_KHR_image_format_list`) were tested and enabled without temporary flags. Tests cover matrices, arrays, dynamic offsets, framebuffer attachments and compatible-format reads/writes. The existing CSF feature policy is retained on G615.

The exact release binary passed **149 CTS cases** and **24 native processes: 34,746 checks and 314 explicitly counted GPU cases** across both consoles. The emulator loaded the exact driver and displayed **Syberia's intro and main menu** on both devices, followed by restoration of the previous selections and settings. This driver-specific check is separate from the owner's earlier RG477M game-folder confirmations.

These results do not establish full Vulkan conformance or FPS superiority. Other devices, firmware versions and long gameplay sessions require their own checks. Corresponding driver sources, licenses and the qualification matrix are attached separately.

## On-screen control editor

Open **Settings → Controls → On-screen controls**, or the editor from the pause menu. Move individual controls, change size and opacity, and use sliders and hints. Save, cancel and reset are available; the game stays paused during editing. The existing button design is retained, and saved layouts are restored on subsequent launches. Physical controller mappings remain separate.

## Sticks and physical controllers

Under **Controls → Gamepads → your controller**:

- A radial dead zone evaluates distance from the centre instead of suppressing a band along each axis.
- Choose the Xbox square range or a circular range. The square option lets a fully deflected diagonal reach the full value of both Xbox axes.
- Adjust each stick's range independently from **50–150%**, alongside existing sensitivity and inversion settings.
- A live test displays the Xbox boundary, circle and movement trace. Controller input is consumed by the test while it is active.

Button/axis mappings, player assignments and device profiles remain available. Legacy GammaPad configurations have **Auto / Off / On** rumble modes. Auto applies a guard to recognized problematic configurations; Off is available when rumble on older GammaOS interrupts a held accelerator. This is an application-side change, not a GammaPad system update or a Magisk module.

## Upscaling and graphics

Added **AMD FSR 1 (EASU + RCAS)** as an additional upscaling filter: edge reconstruction followed by sharpening. Bilinear and SGSR remain available globally and per game. FSR applies when the frame is smaller than its display area; it does not raise the game's internal rendering resolution. Failure to create the intermediate image falls back to Bilinear. Selected CRT effects retain priority.

A cube-map lookup along a zero direction now returns opaque black rather than an unspecified face. This is a general shader change adapted from xbased; it is not a claim that Driv3r was tested on this Android build.

Other renderer changes since 1.5:

- Display a suitable full-size image when a small scratch render target is bound at Present.
- Correct floating-point F16/F24S8 depth representation and clearing.
- Keep retired render targets alive until submitted GPU work finishes.
- Retain the precise surface-height correction for Tomb Raider Legend; the owner confirmed the level flickering was resolved on RG477M.
- Fix the graphics-profile picker: all choices can be reached with touch and the D-pad, with working cancellation.

## Scheduler, memory and file I/O

Selected shared Xbox-kernel changes from [xbased](https://github.com/crazyriddler/xbased), the Windows/Linux edition derived from hakuX, are adapted to our Android ARM64/FEX build:

- Temporary priority boosts for awakened threads, effective-priority scheduling, and boost decay at yield/quantum end. Boost-control exports now implement their behavior instead of remaining stubs.
- I/O completion ports: create, queue, remove, wait, query and associate file operations. Queues grow as needed and are preserved in emulator states.
- Enforce file sharing before overwrite/truncation. Conflicting opens are rejected, so an incomplete HDD-cache copy is not treated as a finished file.

These changes improve Xbox behavior across titles; they do not establish compatibility with every game fixed by xbased on a PC.

The kernel pool starts smaller and grows when needed. Failed memory allocations roll back, memory bookkeeping and asynchronous file positions are corrected. A missing optional XBE library-version table no longer makes the loader reject a valid executable. This changes the emulator loader without rewriting game files.

## Network waits, timers and video

- Network receive waits use the same monotonic clock as their deadlines, avoiding immediate repeated timeouts caused by mixed clocks.
- Guest time accounts for long host-side CPU holds. Deadline rearming during stopped time and the NV2A PTIMER alarm are corrected.
- XMV decoder shutdown is coordinated with audio completion, including skipped introductory movies.
- States retain the necessary display, thread, I/O queue and file-association information.

Network changes do not constitute separate validation of online services or multiplayer.

## HUD

The compact single-line FPS, average/latest frame time and available temperatures are retained. Optional additions:

- **SPEED** measures virtual Xbox clock progress against the device's monotonic time. A value of 100% describes that clock; assess gameplay progress with FPS and observed behavior as well.
- **PACE≈** compares FPS with an explicit reference chosen by the user: 25/30/50/60/120. No reference means no estimate. The emulator's FPS cap is not used as the game's reference rate.

During startup and after pauses, unavailable measurements display “--”. Additional diagnostic lines have not been restored.

## Games, updates and validation scope

Confirmed startup/rendering fixes since 1.5 also include:

- **Need for Speed: Underground:** the loader accepts an XBE without the optional library-version table, without modifying the executable.
- **The Simpsons: Road Rage:** removed the 4096-entry graphics-allocation bookkeeping limit that could stop race loading while RAM remained free. The owner confirmed a race loaded.
- **Tomb Raider: Legend:** displaced 640×448 surface views retain their precise height inside 640×480 buffers, resolving the level flicker confirmed by the owner.
- **Halo:** the owner confirmed startup past the menu with the memory fixes present.
- **Spider-Man:** one owner copy required its folder paths/layout to be restored. This is a separate copy-specific repair; the APK does not include those game resources.

Earlier Syberia, Serious Sam, Prince of Persia and other fixes are retained. The owner confirmed the games in their tested RG477M folder work; see the [compatibility list](../docs/COMPATIBILITY.en.md) for evidence and copy-specific limitations.

The [Russian Serious Sam instructions](../docs/SERIOUS-SAM.ru.md) remain available; the owner confirmed Russian voice audio survives that workaround. The emulator does not rename XBE files automatically.

The final build passed **101 Android unit tests** and release lint. The same native core passed **2841 CPU checks on RG477M** and a full Android ARM64 NDK link. Beyond Good & Evil's introductory movie ran on RG477M with FSR at 640×480 → 1280×960; the controller screen, HUD and settings preservation were checked. These are functional checks, not a comparative FPS benchmark or a full playthrough. Driver qualification results accompany the package separately.

The final **1.6/code26** APK also passed bundled-P48r1 app checks: Syberia cold launch and the first hotel gameplay scene on RG477M, including the SPEED HUD, pause and resume; Syberia intro and main menu on RG476H. Actual driver identity was verified on both consoles, with no GPU faults or native crashes observed during these windows. Previous driver selections were restored.
