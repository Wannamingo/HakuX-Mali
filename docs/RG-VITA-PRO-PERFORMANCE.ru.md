# ANBERNIC RG VITA Pro: результаты тестов hakuX

[Русский](RG-VITA-PRO-PERFORMANCE.ru.md) | [English](RG-VITA-PRO-PERFORMANCE.en.md)

Дата: **29.10.2026**. APK **1.2.0-rg477m.2-vita.2**, versionCode **12**, исходники исполняемого кода `6c460c8cb1c4eb099784f9df3a28085f93a81dee`. RG VITA Pro: **Rockchip RK3576 / Mali-G52 / Android 14 / GammaOS Next Lite**, kernel 6.1.141, около 4 ГБ RAM.

## Что проверено

Семь конфигураций на одном Slot 1 **Need for Speed: Most Wanted - Black Edition**, Xbox title ID `4541007B`, версия игры 7. Каждый короткий замер длился около 60 секунд после снятия игровой паузы. Отдельно выполнен пятиминутный прогон в 2x.

| Режим | Средний FPS | Диапазон FPS за 5 с | CPU / GPU, максимум °C |
|---|---:|---:|---:|
| MaliSX2 0.2.3, 1x | 30.0 | 30.0-30.0 | - / - |
| MaliSX2 0.2.3, 2x | 21.4 | 20.2-22.1 | 66.5 / 67.5 |
| Системный, 1x | 30.0 | 30.0-30.0 | 60.1 / 60.1 |
| Системный, 1x + FXAA | 30.0 | 30.0-30.0 | 66.5 / 65.6 |
| Системный, 2x | 29.9 | 29.7-30.0 | 65.6 / 67.5 |
| Системный, 3x | 18.1 | 15.9-19.6 | 68.4 / 71.2 |
| Системный, 4x | 10.1 | 9.2-13.1 | 69.3 / 72.1 |
| Системный, 2x, 5 мин* | 30.0 | 29.9-30.0 | 71.2 / 73.0 |

Средний FPS рассчитан по предъявленным кадрам и длительности окон из `hakuX-hle-fps`, первые два окна после возобновления исключены. Диапазон - минимум и максимум пятисекундных окон, **не 1% low**. Полный ряд температур первого прогона MaliSX2 1x не сохранился; отсутствующие значения не подменены показателями меню паузы.

\* Пять минут включают активную сцену гонки и экран результатов после выбывания. Первые **120 секунд** подтверждены как активная сцена гонки, средний FPS на этом участке **30.0**. На снимке 142 с видно выбывание, с 160 с - результаты. Это не пять минут непрерывного заезда. Максимумы за весь прогон: **CPU 71.2 °C / GPU 73.0 °C / батарея 36.0 °C**.

## Рекомендуемые профили для этой сцены

| Профиль | Настройки | Результат |
|---|---|---|
| Минимальная нагрузка | System driver, 1x, FXAA Off, Bilinear | 30 FPS; начальный вариант для длительной игры |
| Средний / баланс | System driver, 1x, FXAA On, Bilinear | 30 FPS в минутном тесте со сглаживанием |
| Максимальная чёткость | System driver, 2x, FXAA Off, Bilinear | 29.9 FPS в минутном тесте гонки, выше нагрев |

3x и 4x для проверенной сцены не рекомендуются: около 18 и 10 FPS. В конце 4x Thermal HAL дополнительно сообщил GPU 73.9 °C и `mStatus=3 (SEVERE)`. Частоты не фиксировались, величина троттлинга не установлена. Для меньшего нагрева использовать 1x. На консоли после проверки оставлены System driver и индивидуальные 1x / FXAA Off для Most Wanted; общий масштаб других игр сохранён.

Во всех замерах: 16:9, асинхронные шейдеры On, предварительная сборка кэша On, Bilinear, Uncapped frame rate Off, верхний лимит **120 FPS**. Лимит не отменяет собственную частоту игры. Переключение GPU-драйвера глобальное, изменение масштаба проверялось индивидуально для игры. Драйвер применяется после перезапуска. 1x/2x/3x/4x соответствовали внутренним кадрам 640x480 / 1280x960 / 1920x1440 / 2560x1920; вывод - 1920x1080. Новое сравнение 4:3 и 16:9 на Vita Pro этим замером не проводилось.

## Методика и ограничения

- Сохранение загружалось заново, затем возобновлялась гонка. Газ удерживался экранным контроллером без руления, часть времени автомобиль стоял у ограждения. Полный круг и трасса не проходились. Слот не перезаписывался.
- Температуры опрашивались примерно раз в 5 с: максимум `bigcore-thermal` / `little-core-thermal`, отдельно `gpu-thermal` и `cw221X-bat`. Это максимумы выборок, не непрерывные пики. Сам HUD обновляется раз в 2 с.
- Тесты последовательные, консоль прогрета и заряжается по USB; температура помещения, яркость и фиксированные частоты не контролировались. Автоматические тепловые ограничения не отключались. Температуры нельзя напрямую сравнивать как эффективность драйверов. Автономность и сессии 30-60 минут не измерены.
- Ранее DOA Xtreme Beach Volleyball достигла вступления/титульной сцены примерно при 60 FPS; экранный Start и температурный HUD проверены. Это **не замер игрового уровня**.
- Список 31 подтверждённого запуска относится к RG477M и **не переносится автоматически на Vita Pro**. Другие игры и прошивки требуют отдельной проверки.

## Исходный сбой GPU

MaliSX2 в одном запуске Most Wanted при 2x сообщил `0x60 (out of memory)` для vertex/tiler/compute atom; затем эмулятор получил `VK_ERROR_DEVICE_LOST` в `vkWaitForFences`. Это нехватка памяти при выполнении графической задачи, не доказательство исчерпания всей RAM. В момент исходного сбоя HUD показывал примерно CPU 51 / GPU 50 / батарея 32 °C, поэтому приписывать этот сбой перегреву оснований нет.

В контролируемых повторах ошибка не повторилась, но **исправление дефекта MaliSX2 не заявляется**. Практический вариант для Most Wanted - системный драйвер и 1x, затем при необходимости 2x.
